# Abrxos — empezar o retomar
Leer en orden: AGENTS.md, CONTEXTO.md, ARQUITECTURA.md, ROADMAP.md, ESTADO_ACTUAL.md, DECISIONES.md y la tarea activa en Tasks/.
El repositorio es la fuente de continuidad; los chats no actualizan estos archivos automáticamente.
Antes de trabajar: revisar git status y la tarea activa. Conservar cambios existentes.
Después: registrar resultados, revisar diff y guardar un commit coherente. Publicar en GitHub es un paso separado.
Estos documentos son una base de diseño, no evidencia de funciones implementadas.
